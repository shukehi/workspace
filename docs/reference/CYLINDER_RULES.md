## 概述

系统会自动从订单中提取锁芯信息，并根据以下规则生成采购明细：

- **主锁芯**：从 `sx`（锁具配置）字段提取
- **副锁芯**：从 `fssx`（副锁锁芯）字段提取
- **一个订单可同时生成主锁和副锁两条采购明细**

## 主锁芯规则

### 1. 基础尺寸规则

系统根据**门厚**自动匹配锁芯长度和偏心参数：

| 门厚 | 锁芯代码 | 偏心参数 |
|------|---------|---------|
| 5cm  | 70AB    | 30*40/中心孔偏心 |
| 7cm  | 90AB    | 34.5*55.5/中心孔偏心 |
| 9cm  | 110AB   | 40*70/中心孔偏心 |
| 10cm | 120AB   | 41*79/中心孔偏心 |

### 2. 特殊护罩规则

某些护罩配置会**覆盖**标准尺寸规则：

#### 规则1：16-7-5+ZS17（7cm门厚）
- **触发条件**：`sxhz` 字段包含 `"16-7-5+ZS17"`
- **内开**：84AB，偏心 28*56
- **外开**：84AB，偏心 34*50

#### 规则2：16-1-5+ZS4（7cm门厚）
- **触发条件**：`sxhz` 字段包含 `"16-1-5+ZS4"`
- **内开/外开**：78AB，偏心 28*50（不区分）

#### 规则3：凸护罩（7cm门厚）
- **触发条件**：`sxhz` 字段包含 `"凸护罩"`
- **内开/外开**：81AB，偏心 29*52（不区分）

### 3. 供应商映射

系统根据 `sx` 字段的值自动匹配供应商和产品名称：

| 内部名称 | 供应商 | 外协名称模板 |
|---------|--------|-------------|
| 90P35锌合金锁芯扣封 | 忠恒 | {code}微珠锌合金锁芯 ORIGINAL&SED(TURKEY) |
| 塑2铜锁芯 | 劲佳 | {code}塑2铜锁芯 |
| 锌合金高低齿 | 兴泰锁芯 | {code}锌合金高低齿铜锁芯 |
| ZH-微珠锌合金MAN | 忠恒 | {code}微珠锌合金锁芯 Craft-MAN标 |
| ZH-微珠锌合金锁芯 | 忠恒 | {code}微珠锌合金锁芯 |
| JJ-锌合金子母 | 劲佳 | {code}电镀锌合金子母珠 |

> **注意**：`{code}` 会被实际的锁芯代码替换（如 90AB）

## 副锁芯规则

### 1. 标准规格（7cm门厚）

| 开向 | 锁芯代码 | 偏心参数 | 备注 |
|------|---------|---------|------|
| 内开 | 90 | 30*60/中心孔偏心 | 旋钮在长一边 |
| 外开 | 90 | 35*55/中心孔偏心 | 旋钮在短一边 |

### 2. 特殊规格：哑黑护罩（9cm门厚）

- **触发条件**：`fshz` 字段包含 `"哑黑护罩"`
- **内开**：105，偏心 37*68，备注"旋钮在一边"
- **外开**：暂无数据

### 3. 副锁标识

- 所有副锁产品名称前会自动加 **`(副)`** 前缀
- 所有副锁备注会自动添加 **`5A钥匙`**

**示例**：
```
产品名称：(副) 90铜带菱形旋钮
备注：旋钮在短一边, 5A钥匙
```

## 钥匙配置规则

主锁芯的钥匙配置根据**客户部门**和**锁芯型号**自动确定：

### 决策流程图

```
客户名称包含"三部"？
├─ 是 → 锁芯型号 = "ZH-微珠锌合金MAN"？
│         ├─ 是 → 钥匙 1+5 英文说明书
│         └─ 否 → 钥匙 2+5 英文说明书
│
└─ 否 → 客户名称包含"一部/二部/六部"？
          ├─ 是 → 钥匙 2+5 中文说明书
          └─ 否 → 【待确认】钥匙配置 ⚠️
```

### 配置表

| 客户部门 | 锁芯型号 | 钥匙配置 |
|---------|---------|---------|
| 三部 | ZH-微珠锌合金MAN | 钥匙 1+5 英文说明书 |
| 三部 | 其他锁芯 | 钥匙 2+5 英文说明书 |
| 一部/二部/六部 | 任何锁芯 | 钥匙 2+5 中文说明书 |
| **其他/未识别** | 任何锁芯 | **【待确认】钥匙配置** ⚠️ |

> ⚠️ **重要提示**：当看到 `【待确认】钥匙配置` 时，需要人工核对客户信息并手动修改采购单备注。

## Logo刻标检测

系统会自动检测是否需要刻制商标，检测顺序如下：

1. **优先级1**：检查订单行的 `xsbz`（销售备注）字段
2. **优先级2**：检查整单的 `remark`（订单备注）字段
3. **优先级3**：检查 `customerName`（客户名称）字段

### 支持的Logo列表

- MEGASTAR
- Craft
- ORIGINAL&SED(TURKEY)
- VAnric
- Railingo
- HOME SECURE

### 检测示例

如果在备注中发现 `"需要刻 MEGASTAR 标"`，系统会：
1. 在备注中添加 `(刻 MEGASTAR 标)`
2. **确保该商品不会与无Logo的同规格商品合并**

## 配置文件说明

### 文件位置
`/data/config/cylinder-mapping.json`

### 配置结构

```json
{
  "dimensions": {
    // 主锁芯标准尺寸
    "7": { "code": "90AB", "eccentricity": "34.5*55.5/中心孔偏心" }
  },
  "specialRules": [
    // 主锁芯特殊规则
    {
      "conditionField": "sxhz",
      "keyword": "16-7-5+ZS17",
      "thickness": "7",
      "variants": {
        "内开": { "code": "84AB", "eccentricity": "28*56/中心孔偏心" }
      }
    }
  ],
  "secondaryDimensions": {
    // 副锁芯标准尺寸
    "7": {
      "variants": {
        "内开": {
          "code": "90",
          "eccentricity": "30*60/中心孔偏心",
          "remark": "旋钮在长一边"
        }
      }
    }
  },
  "secondarySpecialRules": [
    // 副锁芯特殊规则
  ],
  "mappings": {
    // 锁芯名称映射
    "ZH-微珠锌合金锁芯": {
      "supplier": "忠恒",
      "template": "{code}微珠锌合金锁芯"
    }
  },
  "customLogos": [
    // Logo白名单
    "MEGASTAR"
  ]
}
```

### 如何添加新规则

#### 1. 添加主锁芯特殊规则

在 `specialRules` 数组中添加：

```json
{
  "conditionField": "sxhz",
  "keyword": "新护罩名称",
  "thickness": "7",
  "variants": {
    "内开": { "code": "85AB", "eccentricity": "30*55/中心孔偏心" },
    "外开": { "code": "85AB", "eccentricity": "35*50/中心孔偏心" }
  }
}
```

#### 2. 添加副锁芯特殊规则

在 `secondarySpecialRules` 数组中添加：

```json
{
  "conditionField": "fshz",
  "keyword": "新副锁护罩",
  "thickness": "9",
  "variants": {
    "内开": {
      "code": "100",
      "eccentricity": "35*65/中心孔偏心",
      "remark": "旋钮在短一边"
    }
  }
}
```

#### 3. 添加新的锁芯供应商映射

在 `mappings` 对象中添加：

```json
"新锁芯名称": {
  "supplier": "供应商名称",
  "template": "{code}产品外协名称"
}
```

#### 4. 添加新的Logo

在 `customLogos` 数组中添加：

```json
"NEW_LOGO_NAME"
```

## 常见问题

### Q1: 为什么有些订单的钥匙配置显示"待确认"？
**A**: 系统无法识别客户所属部门。请检查客户名称是否包含"一部"、"二部"、"三部"或"六部"关键字。

### Q2: 如何确保刻标商品不会被错误合并？
**A**: 系统会自动检测Logo并将其纳入唯一性判断。相同规格但不同Logo的商品会分开显示。

### Q3: 副锁为什么没有生成？
**A**: 检查订单中的 `fssx`（副锁锁芯）字段是否有值。如果为空或"-"，系统不会生成副锁明细。

### Q4: 特殊护罩规则不生效怎么办？
**A**: 确认 `sxhz` 或 `fshz` 字段的值**完全包含**配置中的关键字（如"16-7-5+ZS17"）。
