# 改库前检查清单（2026-03-13）

> 用途：为本地“边开发边使用”的场景提供一页式数据库改动模板。涉及 schema、migration、模型字段语义调整时，先过这一页。

## 改前

1. 备份 `data/runtime/database.sqlite`
2. 备份 `data/config/`
3. 确认这次变更是否只做 additive migration
4. 写清楚会影响哪些表、哪些字段、哪些 JSON 配置
5. 确认是否需要兼容旧字段或旧数据

## 改动中

1. 优先新增字段、表、索引，不直接删旧结构
2. 优先保留旧字段读取兼容，不一步切断历史数据
3. 如需改字段语义，先做回填或兼容读，不直接覆盖旧逻辑

## 不要直接做

1. 不要删字段
2. 不要重建表替换旧表
3. 不要清空 SQLite 后再看功能是否正常
4. 不要只备份数据库，不备份 `data/config/`
5. 不要在没验证 `DB_STORAGE` 的情况下判断“数据丢了”

## 改后

1. 确认应用能正常启动
2. 确认 `schema_migrations` 记录了本次 migration
3. 手工验证订单读取与写入
4. 手工验证入库记录读取与写入
5. 手工验证配方、materials、mappings 配置读取
6. 检查关键页面是否还能打开历史数据

## 出现异常先查

1. 是否切到了错误的 SQLite 文件
2. migration 是否实际执行
3. `data/config/*.json` 是否被覆盖
4. 新字段是否有默认值或兼容读逻辑
