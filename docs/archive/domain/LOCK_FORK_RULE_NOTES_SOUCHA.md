# 锁叉规则

### 普通双台阶 5、7公分锁叉:

小于2200基础尺寸:
上头:570*301
下头:570*301

大于等于2200基础尺寸:
上头:570*376
下头:570*376

**计算方式:**
    门洞高度一共有2档,第一档小于2200,按2050基础门洞高度,第二档大于等于2200;按2200基础门洞高度;

    第一档小于2200的计算方式:实际高度 - 基础高度 /2,计算都得到的结果平分到锁叉的上下头;
    举例:"spec": "960*2100/7/内开外包";
    2100 - 2050 = 50 / 2 = 25

    上头:570+301 + 25 = 896
    下头:570+301 + 25 = 896

    第二档大于等于2200的计算方式:实际高度 - 基础高度,计算都得到的结果加在锁叉上头
    举例:"spec": "960*2300/7/内开外包";
    2300 - 2200 = 100

    上头:570+376 + 100 = 1046
    下头:570+376  = 946
