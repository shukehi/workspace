## 目标范围

- 新增“映射管理”工作台
- 支持三类映射的草稿编辑、发布、回滚、历史查看
- 服务端字段级报错能在前端正确展示
- 第一版优先可用性，不追求复杂可视化规则编辑器

## 产品策略

1. 包装映射优先做结构化编辑。
2. 锁芯、锁叉第一版建议采用“JSON 编辑器 + 校验 + 历史 / 回滚”。
3. 所有类型共用一套 revision / publish / rollback 页面骨架。
4. 差异展示、发布前校验、错误定位，比复杂编辑体验更重要。
