## 实施原则

1. 先复用现有 formula 工作流模式，不重新发明流程。
2. 先支持固定 3 个 profile：`packaging`、`cylinder`、`lock_fork`。
3. 先把包装、锁芯、锁叉都作为“单 profile 大 JSON payload”管理，不做关系型拆分。
4. 先完成后端可用、迁移可回放、运行态可读。
