# Archive Docs

`docs/archive/` 保存历史迁移方案、旧实现说明和阶段性总结。

这些文档可以用于追溯背景，但不应作为当前代码结构、开发流程或配置接入方式的依据。

当前已归档的子类包括：

- `roadmaps/`：历史路线图、旧阶段清单、退场计划
- `progress/`：历史阶段进度、旧 smoke/checklist、迁移批次记录
- `backend-ts/`：后端 TypeScript 迁移与后端架构优化相关历史材料

使用原则：

- 需要现行开发规范时，优先查看 `docs/governance/`
- 需要当前重构路线图时，优先查看 `docs/roadmaps/`
- 需要当前阶段结果时，优先查看 `docs/progress/`
- 只有在追溯历史决策或排查旧实现来源时，才查看本目录
