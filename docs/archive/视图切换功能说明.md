# 采购订单管理 - 视图切换功能

## 功能概述

为"采购订单管理"页面添加了卡片视图和列表视图的切换功能，让用户可以根据自己的偏好选择不同的显示方式。

## 功能特性

### 1. **双视图模式** 🎯

#### 卡片视图（Grid View）
- **布局**：3列响应式网格布局
- **展示方式**：每个采购订单以卡片形式展示
- **优势**：
  - 视觉效果更好，信息层次清晰
  - 适合浏览和快速查看订单概况
  - 卡片hover效果提供良好的交互反馈
- **包含信息**：
  - 采购单号（绿色pill样式）
  - 状态标签（pending/completed/cancelled）
  - 供应商
  - 类型
  - 包含订单
  - 生成时间
  - 操作按钮（查看、打印、删除）

#### 列表视图（List View）
- **布局**：结构化表格布局
- **展示方式**：表格行形式展示所有订单
- **优势**：
  - 信息密度更高，可以一次看到更多订单
  - 便于对比和筛选
  - 适合数据导出和批量查看
- **表格列**：
  - `#` - 序号
  - `采购单号` - 采购订单编号
  - `状态` - 订单状态徽章
  - `供应商` - 供应商名称
  - `类型` - 订单类型（带标签）
  - `包含订单` - 源订单号
  - `生成时间` - 创建时间戳
  - `操作` - 图标按钮（查看、打印、删除）

### 2. **视图切换按钮** 🔘

位置：页面标题右侧，操作按钮左侧

**设计特点**：
- **图标化设计**：使用SVG图标表示不同视图
  - 🔲 网格图标 = 卡片视图
  - ☰ 横线图标 = 列表视图
- **Active状态**：
  - 激活的按钮显示绿色背景
  - 未激活的按钮为灰色，hover时显示浅绿色
- **按钮组样式**：
  - 圆角边框容器
  - 无缝切换按钮
  - 平滑过渡动画

### 3. **响应式设计** 📱

#### 桌面端（> 768px）
- 卡片视图：3列网格
- 列表视图：完整表格（8列）
- 视图切换按钮：横向排列

#### 移动端（≤ 768px）
- 卡片视图：单列堆叠
- 列表视图：
  - 隐藏"生成时间"列以节省空间
  - 字体和padding缩小
- 视图切换按钮：上下排列

## 实现细节

### HTML结构

```html
<!-- 视图切换按钮组 -->
<div class="view-toggle-group">
    <button class="view-toggle-btn" :class="{ active: viewMode === 'grid' }">
        <!-- 网格图标SVG -->
    </button>
    <button class="view-toggle-btn" :class="{ active: viewMode === 'list' }">
        <!-- 列表图标SVG -->
    </button>
</div>

<!-- 卡片视图 -->
<div v-if="viewMode === 'grid'" class="po-grid-container">
    <!-- 卡片内容 -->
</div>

<!-- 列表视图 -->
<div v-if="viewMode === 'list'" class="po-list-container">
    <table class="po-list-table">
        <!-- 表格内容 -->
    </table>
</div>
```

### JavaScript状态管理

```javascript
// 在OrdersTab组件中
const viewMode = ref('grid'); // 默认卡片视图

// 切换通过v-model绑定实现
@click="viewMode = 'grid'" // 切换到卡片视图
@click="viewMode = 'list'" // 切换到列表视图
```

- CSS transition使用GPU加速

## 使用方法

### 切换到列表视图
1. 点击标题右侧的"横线"图标按钮
2. 页面将切换为表格视图

### 切换回卡片视图
1. 点击标题右侧的"网格"图标按钮
2. 页面将恢复为卡片视图

### 在列表视图中操作
- 点击眼睛图标：查看订单详情
- 点击打印机图标：打印订单
- 点击垃圾桶图标：删除订单
