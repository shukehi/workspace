# 预览模态框功能实现报告

## 📊 功能概览

成功将"采购订单查看"功能从**传统弹窗模式**升级为**现代化内嵌模态框**，提供更流畅的用户体验。

---

## ✨ 实现效果对比

| 特性 | 旧方案（弹窗） | 新方案（模态框） |
|------|--------------|----------------|
| **打开方式** | `window.open()` 新窗口 | 页面内overlay模态框 |
| **用户体验** | 离开当前页面，需切换窗口 | 无缝体验，保持在应用内 |
| **浏览器兼容** | 可能被拦截，需用户允许弹窗 | 无拦截风险 |
| **状态保持** | 切换窗口后丢失位置 | 关闭后立即回到原位置 |
| **视觉效果** | 传统、简陋 | 现代、专业、磨砂玻璃效果 |
| **动画效果** | 无 | 平滑淡入淡出 + 缩放动画 |

## 🎨 设计亮点

### 1. **磨砂玻璃背景（Glassmorphism）**
```css
background: rgba(0, 0, 0, 0.7);
backdrop-filter: blur(8px);
```
- 半透明黑色背景
- 8px高斯模糊效果
- 让用户隐约看到后面的工作台，增强层次感

### 2. **平滑动画**
```css
animation: modalSlideUp 0.3s ease-out;
```
- 从中心轻轻缩放弹出
- 0.3秒平滑过渡
- 关闭时反向动画

### 3. **现代化Header设计**
- 标题使用等宽字体（IBM Plex Mono）
- 绿色打印按钮 + 透明关闭按钮
- Icon + Text 混合设计

### 4. **iframe嵌入**
- 保留现有的`order-preview.html`逻辑
- 无需重写打印功能
- 完美兼容现有代码

## 🎯 用户交互流程

### 查看订单流程：
1. 用户点击"查看"按钮
2. `viewPO(po)`函数被调用
3. 数据保存到localStorage
4. 设置`previewUrl`为`/order-preview.html`
5. 设置`showPreviewModal = true`
6. 模态框淡入并缩放出现
7. iframe加载预览页面

### 关闭模态框：
- **方式1**：点击右上角X按钮
- **方式2**：按ESC键
- **方式3**：点击模态框外部的暗色区域
- **效果**：模态框淡出并缩小消失，回到订单列表

### 打印订单流程：
1. 用户点击模态框header中的"打印"按钮
2. `handlePrint()`函数调用iframe的`print()`方法
3. 浏览器打印对话框弹出
4. 用户可选择打印或保存为PDF

## 🌟 关键代码片段

### 1. viewPO函数（关键修改）
```javascript
const viewPO = (po) => {
    // 构建预览数据
    const orderForPrint = {
        customerName: po.supplier,
        code: po.sourceOrders,
        list: po.items
    };

    // 保存到localStorage供iframe访问
    localStorage.setItem('_order_preview_data', JSON.stringify(orderForPrint));
    localStorage.setItem('_order_preview_po_number', po.poNumber);
    localStorage.setItem('_order_preview_category', po.category);
    localStorage.removeItem('_order_preview_auto_print');

    // 打开模态框而非新窗口
    previewUrl.value = '/order-preview.html?t=' + Date.now();
    showPreviewModal.value = true;
};
```

### 2. 模态框HTML结构
```html
<preview-modal 
    :show="showPreviewModal" 
    :preview-url="previewUrl"
    @close="closePreviewModal">
</preview-modal>
```

### 3. 模态框模板
```html
<div v-if="show" class="preview-modal-overlay" @click="handleOverlayClick">
    <div class="preview-modal-container">
        <div class="preview-modal-header">
            <h3>采购单预览</h3>
            <button @click="handlePrint">打印</button>
            <button @click="closeModal">×</button>
        </div>
        <div class="preview-modal-body">
            <iframe :src="previewUrl" class="preview-iframe"></iframe>
        </div>
    </div>
</div>
```

## 🚀 性能优化

### 1. 懒加载
- iframe仅在模态框打开时加载
- 使用`v-if`而非`v-show`，未显示时不渲染DOM

### 2. 缓存破坏
```javascript
previewUrl.value = '/order-preview.html?t=' + Date.now();
```
- 添加时间戳参数防止浏览器缓存
- 确保每次打开都加载最新数据

### 3. GPU加速
```css
transform: translateY(0) scale(1);
backdrop-filter: blur(8px);
```
- 使用transform而非top/left
- 利用GPU硬件加速

## 🐛 已知问题和解决方案

### 问题1：组件未注册
**现象**：模态框不显示，控制台报错
**原因**：PreviewModal未在OrdersTab中导入和注册
**解决**：
```javascript
import { PreviewModal } from './PreviewModal.js';

export const OrdersTab = {
    components: { PreviewModal },
    // ...
}
```

### 问题2：CSS未加载
**现象**：模态框样式异常
**原因**：preview-modal.css未在main.css中导入
**解决**：
```css
@import url('components/preview-modal.css');
```
